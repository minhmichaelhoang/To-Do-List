# Frontend

React + Vite + TypeScript Frontend, Teil des `to-do-list` npm-Workspaces-Monorepos (siehe `backend/` und `shared/` im Projekt-Root).

## Entwicklung

Aus dem Projekt-Root:

```bash
npm run dev
```

Startet den Vite-Dev-Server. Erwartet das Backend unter `http://localhost:3000` (Start über `npm run start:server` im Projekt-Root).

## Tests

```bash
npm run test
```

Component-Tests liegen in `test/`, gespiegelt zur Struktur von `src/`.
